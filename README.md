# Dynamic-Multilevel-Dropdown-Menu
Dynamic Multilevel Dropdown Menu connected with mysql database using Bootstrap and procedural PHP
# Requirements to make this page work 
1) you need to create customer database on your xammp server.
2) you need to have region table which hold (regionId, regionName).
3) then a zone table which holds (regionId(fk),zoneId,zoneName).
4) then a town table (zone Id(FK), townName, townId)
